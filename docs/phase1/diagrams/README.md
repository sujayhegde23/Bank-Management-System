## Updating a Diagram

The use case diagram is generated by a Python script. From the repository root:

```bash
python docs/phase1/diagrams/use_case_diagram.py
```

For the Mermaid diagrams:

Run the automated build script:

```bash
python docs/phase1/diagrams/build_diagrams.py
```
