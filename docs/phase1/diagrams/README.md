## Updating a Diagram

The use case diagram is generated by a Python script. From the repository root:

```bash
python3 docs/phase1/diagrams/use_case_diagram.py
```

For the Mermaid diagrams:

1. Edit the Mermaid block in the `.md` source file.
2. Preview it on GitHub or at <https://mermaid.live>.
3. Regenerate the PNG so the architecture document stays in sync, for example
   with the Mermaid CLI:

   ```bash
   npx -p @mermaid-js/mermaid-cli mmdc -i diagram.mmd -o diagram.png -s 2 -b white
   ```

   (Copy the Mermaid block into `diagram.mmd` first.)
